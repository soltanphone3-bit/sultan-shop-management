# World Clock

A small, responsive digital clock dashboard that shows the current time and date across multiple time zones.

## Run

Open `index.html` in any modern browser. No build step or server is required.

## Features

- Live clocks with seconds and local dates for popular cities.
- Add any time zone supported by the browser and remove clocks you no longer need.
- Remembers your selected clocks in browser local storage.
- Responsive layout for desktop and mobile.
